# neat-fern-lite

Edge Computing · Rust · WebAssembly

给自己省点事的小工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/neat-fern-lite.git
cd neat-fern-lite
cargo build --release
```

## 备注

就是给自己省点事，没做太多抽象。
